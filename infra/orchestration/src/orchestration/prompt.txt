### 3. Pull the Embedded JSON (quickest way)

1. Use the **shell tool** to download the raw HTML of the current page:

   ```bash
   curl -s https://supercell.com/en/games/clashroyale/blog/page/1/ > page1.html
   ```

2. In the saved `page1.html`, locate the line beginning with `<script id="__NEXT_DATA__"`.
   - It contains a complete JSON object.
   - The field `props.pageProps.articles` is an array of article objects.

3. Extract the JSON with a simple **grep/awk** (or any text‑processing you have) e.g.:

   ```bash
   grep -o '{"props":{.*"</script>' page1.html | sed 's/<\/script>//' > page1.json
   ```

   *If your environment lacks regex tools, you can read the whole file into a variable and split on `</script>` until you find the string containing `"articles"`.*

4. **Parse** `page1.json` (most agents can `json.loads`).
   - For each entry in `json["props"]["pageProps"]["articles"]` collect:
     - `title`
     - `linkUrl`
     - `publishDate` (ISO string)

5. **Filter by date**
   - Keep only articles whose `publishDate` ≥ `2026‑08‑01T00:00:00Z`.
   - Discard any title that clearly mentions an alternate mode (e.g., contains “Merge Tactics”).

6. **Result**: a list of candidate URLs (e.g., `"/en/games/clashroyale/blog/news/final-august-balance-changes-826"`).

---

### 4. Follow Pagination (if needed)

1. After processing page 1, check if the **last article’s date** is still after `2026‑08‑01`.
   - If yes, you may have missed newer entries on page 2 (unlikely for recent dates but safe to verify).
2. To get page 2, repeat **Steps 2‑3** with URL `.../page/2/`.
3. Continue until the first article on a page is **earlier** than `2026‑08‑01`; then stop.

### 5. Visit Each Candidate Article for Details

For each retained `linkUrl`:

1. Build the full URL: `https://supercell.com` + `linkUrl`.
2. Navigate to it (same session) **or** fetch it via `curl` (faster, no extra session state needed). Example:

3. Again locate the `__NEXT_DATA__` script and parse the JSON. The fields you need are:

### 7. Common Pitfalls & How to Avoid Them

| Pitfall | Why it Happens | Fix |
|---------|----------------|-----|
| **Session name rejected** | Minimum length = 10 characters. | Always count characters. |
| **Parsing HTML instead of JSON** | HTML structure is heavy and changes often. | Directly extract the `__NEXT_DATA__` script; it is stable. |
| **Missing articles because of pagination** | Assuming all recent items fit on page 1. | Keep paging until the oldest article on the page is before the cutoff. |
| **Confusing season announcements with balance updates** | Some season posts only describe new game modes. | Scan `bodyCollection` for concrete card‑stat changes; ignore pure narrative sections. |
| **Incorrect date comparison** | Timezones (e.g., `+03:00` vs `Z`). | Strip the time part; compare only the date string or convert to UTC before comparison. |
| **Including Merge‑Tactics items** | Title contains “Merge Tactics”. | Filter out any title that contains the substring “Merge Tactics”. |
| **Forgetting to URL‑encode link paths** | Some `linkUrl` may contain spaces or special chars. | Use the raw `linkUrl` as provided; they are already URL‑safe on Supercell site. |
